How much, who, and when

Daily spend is estimated from token counts at current Bedrock on-demand list prices, grouped by model family. Per-user cost is normalized by active days to separate heavy adopters from one intense week.

02

Where the dollars actually go

Agentic sessions re-read the whole conversation every turn, so cache reads and writes — not typed prompts — dominate cost. A 5-minute cache write carries a 1.25× premium; a cache that expires between turns gets re-written from scratch.

03

How people actually use Claude Code

Sessions are reconstructed by grouping each user's invocations into runs with less than 30 minutes between calls. Tool names are parsed from response payloads; hours are local America/New_York time.
